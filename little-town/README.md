# little town. — 習慣から育つ小さな街

MUZE TOOL BOX 内の、1人用・ブラウザ保存のハビットトラッカー。

## 機能
- タスクを最大3つ登録・編集・削除。各タスクは1日1回だけ「できた！」を記録。
- 自分のキャラクター画像（PNG / JPG / WebP / GIF）を読み込んで、左右に歩かせられる。
- 画像アップロード時にプレビュー、単色背景の切り抜き（強さ調整）、余白トリミング、元画像へ戻す、保存。背景透過はブラウザ内処理で、写真等の複雑な背景には非対応。GIFの編集結果は静止画像になる。既存のキャラクターは保存操作まで変更されない。
- 達成累計でSketch Townの木・家・屋根・お店・噴水・風車と四隅の草花が増える。お休みしても街は減らない。
- 未来の街のプレビューは記録に加算されない。
- localStorageへの保存と書き込み確認。JSONバックアップ・復元に対応。
- 外部CDNを使用せず、KenneyのPNGを同梱。

## デザイン・履歴
- コピーを減らし「HOW TO USE」にまとめ、Kenney Sketch Townに合わせたポップなゲームUIに変更。
- カード状パネルをなくして、街・タスク・キャラクター・履歴を区切り線で整理。
- 履歴に月別達成カレンダー、日別ログ、達成日数、現在の連続日数、最長連続日数を表示。
- 以前の保存キーを維持し、既存のタスク・達成履歴を引き継ぐ。連続日数は1日でも1タスク達成した日をカウント。

## データについて
記録はこのブラウザ（localStorage キー: `little-town-rikomuze-v1`）に保存され、端末間同期はなし。ファイルプレビューやプライベートブラウズでは保存が制限されることがあるため、アプリ上で警告する。

## 素材
Kenney Sketch TownのPNG 27種類を使用。CC0 1.0ライセンス。
https://kenney.nl/assets/sketch-town

## 公開について
- A案のホーム画面アイコン（180 / 192 / 512px）、manifest.json、OGPを設置済み。
- MUZE TOOL BOX 内の `little-town/` ページとして公開。その他のツールの保存領域とは独立。

## 開発プレビュー
変更は `little-town/preview/` で確認してから本番へ反映する。プレビューは独立した保存キーを使用し、実利用者の記録には干渉しない。装飾のデザインと配置が確認できるまで本番に反映しない。

## 季節モード・クリスマス装飾・ポストカード
- 既存の `little-town-rikomuze-v1` のタスク・履歴・キャラ画像を維持。追加設定は `settings.theme` と `townDecor.map01` に保存。
- 通常／冬モードを切り替え。冬の地面・屋根・木はKenney Sketch Town素材からブラウザ内で描画。降雪アニメーションは未実装。
- クリスマス装飾の解放は累計20回ケイン、30回プレゼント、40回リース、50回雪だるま、60回ツリー。未来の街プレビューでは解除されない。
- 獲得済みの装飾は自由配置可能。位置と表示のON/OFFはブラウザ内で保存。コレクションは全マップ共通、配置はマップ別の設計。
- ポストカードは1200×800の街・装飾のみの画像で、キャラあり／なし切替可。共有メニューとX投稿文にサイト名と公開URLを渡す。X投稿画面では画像を手動添付。
- 開発プレビュー `little-town-preview-v1` と本番の保存領域は分離。

- DAILY QUEST は街の直下。飾りの解放条件と本番の保存キー・履歴・キャラクターは維持。未来の街は記録に加算されない。
- ポストカードにも花・雪の低木・新リースを描画。
