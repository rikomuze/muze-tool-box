# MUZE PROFILE v1

MUZE向けプロフィールカードメーカー。

## 項目
- NAME / X ID（任意）
- BIAS
- 沼ポイント
- 一番好きなビジュ
- 好きな曲 TOP3
- 初現場
- 次の現場
- 遠征エリア（複数選択）

## UX
- 曲は検索 + タップで最大3曲
- 選択順がそのままTOP1〜3
- 遠征エリアは複数選択
- ビジュは既存の「最強9マス」アー写編＋パフォ衣装編の素材を参照
- デザインは EDITORIAL / PHOTO / MINIMAL / SOFT の4種
- 結果画像は 1080×1350 PNG

## Data
楽曲名・ライブ名はMAZZEL公式サイト / UNIVERSAL MUSIC JAPANの公開情報をもとに整理。
